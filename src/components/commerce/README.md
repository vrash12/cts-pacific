# Commerce components

This directory remains dormant while `NEXT_PUBLIC_ECOMMERCE_ENABLED=false`. The private admin workspace may report catalog and payment readiness, but product, cart, checkout, PayPal, and card controls must not be exposed publicly until the full commerce launch checklist is complete.

Card payments are planned through provider-hosted fields. Raw card numbers, security codes, and browser-supplied prices must never enter CTS Pacific application storage.
